Hermes DevLoop — Human-Mentored Agentic Engineering

Agentic Engineering · Software Architecture · Engineering Experimentation

Hermes DevLoop is an open-source experiment exploring whether AI coding agents can develop better engineering judgment through sustained human mentorship, feedback, and practical experience.

I'm developing a supervised engineering environment where an agent can investigate issues, work with source code, develop solutions, and propose changes for human review. The system emphasizes appropriate autonomy, clear engineering responsibilities, and measurable outcomes.

The central question is whether mentorship can produce improvements that extend beyond following instructions or remembering previous corrections—particularly when an agent encounters unfamiliar engineering challenges.

Technologies: Hermes Agent, Python, Docker, GitHub Apps, Model Context Protocol (MCP), GitHub.

Status: Active development and experimentation.

Fitness Competition Platform

Full-Stack Development · Mobile Architecture · Simulation & Testing

Designed and developed a mobile fitness competition platform with a TypeScript backend, PostgreSQL database, and Kubernetes-based development environment.

A distinguishing feature was an accelerated simulation that compressed competition lifecycles from days into minutes, allowing stakeholders to interact with the application while synthetic participants exercised its business logic.

Status: Completed working prototype

Technologies: React Native, Expo, JavaScript, TypeScript, Node.js, Express, PostgreSQL, Sequelize, Docker, Kubernetes, Helm.

Careerz Group — Workforce Platform

Agentic Engineering · Full-Stack Architecture · Rapid Product Delivery

Architected and developed a workforce management and talent-matching platform, extending an existing assessment system with organizational management, position criteria, candidate comparisons, and reporting.

Using AI coding agents within an architecture-led development process, I delivered the initial application to production in approximately three weeks.

Technologies: TypeScript, React, Node.js, Express, PostgreSQL, Prisma, OpenAPI, Vite, TanStack Query.

Status: Production release; ongoing development.

Subjective Wine — AI-Powered Wine Discovery

Applied AI · Mobile Architecture · Agentic Engineering · Observability

Designed and developed a mobile application that identifies wines from bottle photographs and generates personalized recommendations.

The architecture combines AI-assisted wine identification and information acquisition with deterministic, content-based recommendation scoring. It emphasizes repeatability, diagnostic visibility, and the ability to investigate individual AI decisions.

The application was developed through coding agents under my architectural direction, with structured engineering practices, automated verification, and explicit attention to security and privacy.

The product is functional and regularly field-tested, with continued work on the mobile experience and human review capabilities.

Technologies: TypeScript, React Native, Expo, Node.js, Express, PostgreSQL, Prisma, OpenAI, Docker, Kubernetes, Helm, OpenTelemetry, Grafana, Prometheus, Loki, Tempo.

Status: Functional and actively field-tested; pre-beta.
