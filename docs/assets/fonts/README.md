# Local fonts

All pages use the same bundled Latin WOFF2 files:

- Inter, normal weights 400–600, for body text and navigation.
- Playfair Display, normal weights 500–600, for primary headings.

Retrieved from the Google Fonts CSS API on October 19, 2026, preserving the existing
font families. The files are variable fonts, shared across the selected weights.
They are served by this site. No visitor request to Google Fonts is needed.

Sources:

- Inter: https://fonts.gstatic.com/s/inter/v20/UcC73FwrK3iLTeHuS_nVMrMxCp50SjIa1ZL7.woff2
- Playfair Display: https://fonts.gstatic.com/s/playfairdisplay/v40/nuFiD-vYSZviVYUb_rj3ij__anPXDTzYgA.woff2

Both fonts use the SIL Open Font License. The original notices are included in
`Inter-OFL.txt` and `Playfair-Display-OFL.txt`, from the corresponding font folders
in https://github.com/google/fonts/tree/main/ofl.
